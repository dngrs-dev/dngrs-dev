## 🚀 Selected Projects

### [Dublaro](https://github.com/dngrs-dev/dublaro) — Local AI Video Dubbing

A command-line tool that turns video into a dubbed version in another language, combining speech recognition, translation, speech synthesis, timing alignment, and subtitles.

- Separate adapters for Faster-Whisper, Ollama, Argos Translate, Piper, and optional speaker diarization and source separation.
- Resumable pipeline stages, batch processing, configuration validation, and diagnostics for inspecting runs and their outputs.
- Pytest tests for adapters, pipeline behavior, and CLI commands; GitHub Actions checks across Linux and Windows.

**Built with:** Python, Typer, Pydantic, FFmpeg, Ollama, Pytest, Ruff.

---

### [Deedbound](https://github.com/dngrs-dev/Deedbound) — Multiplayer Board Game

A browser-based property-trading game with a Python rules engine, FastAPI backend, and HTML, CSS, and JavaScript client.

- Game rules separated from the web layer, with tests for turns, auctions, payments, and player actions.
- WebSocket lobbies and game sessions with server-side validation of player choices.
- Account registration and login, JWT cookie sessions, and SQLAlchemy/SQLite persistence for profiles, inventory, and transactions.

**Built with:** Python, FastAPI, WebSockets, SQLAlchemy, SQLite, JavaScript, Pytest.
